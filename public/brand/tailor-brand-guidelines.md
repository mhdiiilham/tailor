# Tailor — Logo Guidelines

## The logo

**Idea:** A precise T with stitch holes, expressing care in tailoring a CV to each opportunity.

**Versions:** Horizontal lockup for the app header; stacked lockup for narrow placements; symbol-only for avatars and icons.

## Clear space and size

Keep clear space equal to the symbol's stem width (40 units in the 256-unit master) around the logo. Use the small-size symbol for favicons. Keep the symbol at least 20 px tall in interface use; use the horizontal lockup at 140 px wide or larger.

## Colour

| Colour | HEX | RGB | Approx. CMYK* |
|---|---|---|---|
| Tailor berry | `#762D46` | 118, 45, 70 | 0, 62, 41, 54 |
| Soft ink | `#202020` | 32, 32, 32 | 0, 0, 0, 87 |
| White | `#FFFFFF` | 255, 255, 255 | 0, 0, 0, 0 |

Use the berry symbol with soft ink wordmark on white or warm, very pale neutral surfaces. Use the white mark on the berry app tile or a dark background. Black and white single-colour SVGs are included for print and constrained uses. *CMYK values are rough conversions; confirm with the printer and a physical proof.

## Typography

The exploratory wordmark uses Georgia Regular, with Baskerville and a generic serif fallback. The font remains live text in the SVG lockups and is not bundled. Use Georgia for the logo lockup where available; for product interface copy, retain the app's existing type system.

## Use

- Preserve the proportions and spacing in the supplied lockups.
- Use the white version on dark backgrounds and berry/ink versions on light backgrounds.
- Don't stretch, rotate, add effects, or recreate the wordmark with unrelated type.
- Keep the symbol alone for small app and browser icons; stitch marks are intentionally spaced for legibility.

## Files and rights

SVG masters and web icon exports are in `public/brand/`. This concept is not trademark-cleared; search relevant trademark registers before commercial launch.
