# Tailor logo kit

## Direction

The Stitched T turns the crossbar and stem of a T into a carefully finished seam. The restrained stitch holes suggest craft and attention to the candidate's details. The mark uses the Tailor name only; it does not use Taylor Swift's signature, initials, imagery, or other distinctive brand assets.

## Files

- `tailor-symbol.svg` — primary symbol master.
- `tailor-symbol-small.svg` — simplified small-size master for browser and app icons.
- `tailor-horizontal.svg` — primary horizontal lockup.
- `tailor-stacked.svg` — centered lockup for square or narrow spaces.
- `tailor-horizontal-white.svg` and `tailor-stacked-white.svg` — reversed lockups for dark backgrounds.
- `tailor-symbol-{black,white,mono-762d46,square,favicon,app-icon}.svg` — exported variants.
- `favicon.ico`, `favicon.svg`, PNG web icons, and `site.webmanifest` — web and app icon set.
- `tailor-brand-guidelines.md` — compact usage guidance.

The SVG wordmarks use Georgia with Baskerville and generic serif fallbacks. The type is live text and can render differently if Georgia is unavailable; convert it to outlines in the final production master before handing to a printer.
